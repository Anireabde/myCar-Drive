
# myCar-Drive

A landscape Android dashboard prototype inspired by CarPlay.

## Build APK with GitHub Actions
1. Upload all files and folders in this project to the root of a GitHub repository.
2. Make sure the default branch is named `main`.
3. Open the repository's **Actions** tab.
4. Open **Build myCar-Drive APK** and wait for the run to finish.
5. Download the `myCar-Drive-APK` artifact and extract `app-debug.apk`.
6. Transfer the APK to the Android tablet and install it.

## Shortcuts
Google Maps, Waze, Deezer, Phone dialer, Weather website, Bluetooth settings, YouTube, WhatsApp and Android Settings.

Apps that are not installed open their web fallback where available. Weather opens a web weather page. Bluetooth opens Android Bluetooth settings.

This is a dashboard launcher prototype, not Apple CarPlay or Android Auto certification. Do not use YouTube or interact with the tablet while driving.
